关于我

嘿！我是古晓锋，广东梅州人，广东石油化工学院网络工程专业2027届在读。专注于 DevOps 与云原生运维方向，具备以下技术实践经历：

  • 容器化与编排：Docker 容器化部署、Docker Compose 多服务编排、Kubernetes 集群搭建与资源调度
  • CI/CD 流水线：Jenkins Pipeline 自动化构建与部署，实现代码提交到上线的全流程自动化
  • 负载均衡与代理：Nginx 七层反向代理、负载均衡策略配置、HTTPS 证书管理
  • 数据库运维：MySQL 主从复制架构部署、数据备份与恢复策略
  • 监控与可观测性：Prometheus 指标采集 + Grafana 可视化看板 + 告警规则配置
  • 自动化脚本：Shell / Python 编写运维自动化脚本，覆盖部署、巡检、日志分析等场景
  • 云原生：Kubernetes 集群搭建与管理、容器化应用部署、服务发现与负载均衡
  • DevOps：DevOps 文化实践、持续交付与部署、监控与日志管理
  • 网络配置：路由器/交换机配置（VLAN、静态/动态路由、ACL、VRRP、OSPF）

建这个博客，一是把项目里踩过的坑和学到的经验系统整理成笔记，方便自己复盘回顾；二是希望这些记录能帮到遇到同样问题的同学——毕竟对着终端排错的感觉，谁都不想经历第二次。写下来，下次就能少走弯路。
